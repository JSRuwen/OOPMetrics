# OOPMetrics
A python library for analyzing Chidamber & Kemerer's metrics of Java code through AST parsing.

OOPMetrics is a static analysis tool that extract from the Java programming language code, C&K metrics, not only in one file, but recursively.

# Installation
## From source

```bash
git clone https://github.com/JSRuwen/OOPMetrics.git
cd OOPMetrics
# Make sure you activate venv
pip install -e .
```

# Dependencies
Python >= 3.10
java-ast >= v1.0.3
rich >= 13.0
